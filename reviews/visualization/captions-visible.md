# semion-sum-phase
セミオンの三つの和。左では青の真空の寄与に赤紫のセミオンの寄与を先端から足し、黒で和を示す。右では非ゼロの和を同じ向きの単位ベクトルへ規格化する。両列・全段で軸の単位をそろえた。$n=2$ では和が原点に戻り、位相の方向は定まらない。
各段は n=1、2、3。左の二つの寄与の和は順に 1+i、0、1−i。右の単位円には n=1 の四十五度と n=3 の負の四十五度の位相矢印があり、n=2 には矢印がない。
# stacked-phase-product
二つの相を積み重ねると、エニオンの和は複素数の積になる。共通の軸で描いた上二段の長さ $\sqrt2$ と $2$ は、下段で $2\sqrt2$ になる。時計回りの角度 $-\pi/4$ と $-3\pi/4$ は足され、積は負の実軸を向く。薄い円は各段とも半径 $1$ を示す。
上段は長さ平方根二で角度マイナス四十五度の矢印、中段は長さ二で角度マイナス百三十五度の矢印、下段は長さ二平方根二で負の実軸を向く矢印。長さの積と角度の和が下に記され、規格化した位相はマイナス一。
# modular-inverse-map
右の分子の引数に $(ST^nS)^{-1}$ を作用させ、低温で評価する指標の引数を求める。$n=2$、$\xi_r/L=0.1$ の例では $-0.5+0.1i$ が $0.5+2.5i$ に移る。横軸・縦軸はともに線形で同じ単位を使う。破線の矢印は写像の入力と出力を結ぶ。
実部と虚部の共通線形軸。実部マイナス〇・五、虚部〇・一の青い点から、逆モジュラー写像を示す破線矢印が実部〇・五、虚部二・五の緑の点へ向く。軸への点線投影は虚部の増大を同じ尺度で示す。
# three-phase-correction
セミオンで $n=3$、$c_-=1$ とした位相の合成。各段の矢印は、その因子による符号付き角度の変化を同じ尺度で示す。上の三段は中心電荷の位相 $-11\pi/36$ に達し、エニオンの位相 $-\pi/4$ を加えると観測位相は $-5\pi/9$ になる。最後に既知の補正 $+11\pi/36$ を加えると $\zeta_3$ の位相へ戻る。縦の点線は前段の終点と次段の始点を結ぶ。
共通の角度軸を使った五段の矢印。左側の真空の寄与によるマイナスπ三十六分の一、T三乗のマイナスπ四分の一、右側の真空の寄与によるマイナスπ三十六分の一が左向きに続く。さらにエニオンのマイナスπ四分の一で観測角度マイナス五π九分の一に達する。補正の右向き矢印はプラス十一π三十六分の一だけ戻り、マイナスπ四分の一になる。
# partial-rotation
円筒の表面を開いて示した部分回転。例として n=4 とし、同じ形の印を追うと、A の全体が周方向に L/4 移動して一周を越えた部分が戻る。B の印は動かない。上下の破線は同一の周座標を表し、物理的な境界ではない。左の実線が試料の端、A と B の間の実線がエンタングルメント切断である。
展開した円筒の操作前後。青緑の A 全域の四種類の印が一段ずつ周期的に移動し、灰色の B の印は同じ位置に残る。上下の辺は同一視され、左端と中央の切断はそれぞれ青緑と赤紫の実線で区別される。
# schmidt-trace
シュミット分解の三組を使った例。線は同じ添字の A と B のシュミット状態の組を表す。B の内積を取ると異なる添字の項がゼロになり、A には対角成分の確率だけが残る。示した確率は説明用の値であり、和は 1 である。
A と B のシュミット状態 1、2、3 が同じ添字どうしで結ばれている。B をトレースすると、B の正規直交性により、A の密度行列の非対角成分がゼロになり、対角成分に 1/2、1/3、1/6 が残る。
# schmidt-complex-sum
説明用の二状態の例。破線の円は単位円、矢印は確率を掛けた複素数であり、二つの色はこの図の二つの寄与を区別する。上では同じ大きさの反対向きの寄与が完全に打ち消し合う。下では実軸方向の 3/4 と正の虚軸方向の i/4 の和が斜めの矢印になる。いずれも数値測定の結果ではない。
上の複素平面では原点から実軸の正負の向きに長さ 1/2 の矢印が伸び、和は原点のゼロ。下では正の実軸方向の 3/4 と正の虚軸方向の i/4 の矢印、およびそれらの和 3/4+i/4 が単位円の内側に示される。
# two-edge-density
A の左端とエンタングルメント切断を、それぞれの CFT の密度行列に対応させる。棒の長さは重みの模式的な比較であり、準位間隔や確率の測定値を表さない。左では大きな逆温度が基底状態の重みを優勢にし、右ではエンタングルメントの複数の重みを有限の有効逆温度で表す。二つの因子の積は、端が十分離れたときの低エネルギー近似である。
青緑の A の左に物理的な端、右に赤紫のエンタングルメント切断があり、その外側は灰色の B。下に二つの CFT 因子を縦に並べ、左の物理的な端では最低準位の棒が優勢、右の切断では複数の準位に重みが残る様子を模式的に示す。
# mps-bond-rotation
補足の右半分の部分回転は、全ての右側テンソルに作用する並進を、切断の補助ボンド上の逆変換として評価する。各ボンド状態の位相をシュミット確率で重み付けして足す。下段には、補足のラベルの校正と、本ノートで選んだ A の物理的な運動量の規約をそれぞれ示した。
MPS の右半分全体に付いた操作の括弧と、切断のボンドを拡大した図。複数のボンド状態がそれぞれシュミット確率と逆変換の位相を持ち、それらを足した式に対応する。原点の校正と A の物理的な運動量の式は別に表示されている。
# orbital-realspace-cuts
軌道の切断は軌道の添字を左右へ分ける。実空間の切断では、幅をもつ各 Landau 軌道が $x=x_c$ の両側にもつ重みを分ける。下段は軌道の広がりの模式図であり、数値データや密度の定量的な比較ではない。$x$ は円筒の軸方向、$y$ は周方向である。
上段は並んだ軌道をボンドで二つの添字集合へ分ける。下段は x 方向に広がる三つの軌道を描き、同じ垂直な実空間境界が各軌道の重みを A と B に分ける。
# boundary-integer-membership
$N_{\mathrm{FS}}=12$、$1\le n\le12$ における二つの整数条件の比較。塗りつぶした丸はその条件に含まれる整数、白抜きの丸は含まれない整数を表す。12 と互いに素な整数の集合は Abelian の条件の集合に真に含まれる。non-Abelian な相には前者による必要条件を用いる。Abelian な物理的な相の境界を判定するには、後者の位相条件と実際の $c_-=0$ の両方が必要である。
1 から 12 の整数を同じ行に置いた比較表。12 と互いに素な整数の集合は 1、5、7、11。Abelian の広い条件の集合は 1、3、4、5、7、8、9、11、12 であり、前者を全て含む。
# asymptotic-regimes
対数軸上で比較した二つの漸近領域。固定角の式は $L/\xi_r\gg n^2$、微小角の式は $1\ll L/\xi_r\ll n$ で検討する。点 $(2,100)$ と $(1000,100)$ は本文の例であり、測定値ではない。破線と点線は比較の基準となる等式であって、近似の有効性を保証する境界ではない。$n$ を二倍にすると、固定角の条件で比較する周長の尺度は四倍になる。
横軸 n、縦軸 L と有効エッジ長の比を対数表示する。二乗の基準線の十分上方に固定角の領域、一次の基準線の十分下方かつ比が 1 より十分大きい側に微小角の領域がある。比が 100 で n が 2 と 1000 の二点を示し、固定した n で上へ進む矢印と固定した比で右へ進む矢印を描く。
