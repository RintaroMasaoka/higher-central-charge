# 二乗した値の範囲と一対一性

まず、端点だけを使う方法に頼ってはいけない。一般の関数に通用する万能な方法ではないからである。

実数 $x$ を区間 $[-2,1]$ から選び、$y=x^2$ とする。端点の値は $4$ と $1$ である。一方、区間内の $x=0$ で $y=0$ を取る。$x$ が $-2$ から $0$ に近づくと $x^2$ は $4$ から $0$ に減り、$0$ から $1$ まで進むと $0$ から $1$ に増える。したがって像は $[0,4]$ である。

この区間では $x^2$ は単調ではない。頂点が区間内にあるため、像の端を求める計算では区間の端点に加えて頂点の値も使う。

次に、一つの値 $y$ を与えたとき、元の $x$ が一つに決まるかを考える。$x=-1$ と $x=1$ はどちらも $y=1$ を与える。二つの入力が同じ出力に写るため、この写像は一対一ではない。
